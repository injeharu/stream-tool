# 配信サポートツール(特典台帳)

Twitchのチャットを匿名で監視し、サブスク月数が設定した節目(閾値)に到達した視聴者を
自動で特典待ちリストに載せる、配信者向けの常駐ツールです。

**APIキー・開発者登録は一切不要**。チャンネル名を入れるだけで動きます。

任意で[Twitchと連携](#-twitch連携任意)すると、サブスク名簿やフォロワー一覧なども
見られるようになります(連携しなくても全機能そのまま使えます)。

## セットアップ

### 方法A: インストーラー版(おすすめ・Python不要)

[Releases](https://github.com/injeharu/stream-tool/releases/latest) から
`TokutenDaicho-Setup-vX.Y.Z.exe` をダウンロードして実行するだけです。
インストール後は自動でツールが起動し、ブラウザで管理画面が開きます。

※ 署名なしのアプリのため、初回実行時にWindowsの警告(「WindowsによってPCが保護されました」)
が出ることがあります。「詳細情報」→「実行」で進められます。

※ バージョンアップ直後、ショートカットのアイコンが古いまま表示されることがあります
(Windowsがアイコンを一時的に覚えているためで、動作には影響しません)。
気になる場合はサインアウト→サインインで更新されます。

### 方法B: ソースから実行(開発者向け)

事前に [Python](https://www.python.org/downloads/) をインストールしてください。
インストール時に **「Add python.exe to PATH」にチェック**を入れるのを忘れずに。

1. **`setup.bat` をダブルクリック** — 必要な部品を自動でインストールします(初回のみ)
2. **`start.bat` をダブルクリック** — ツールが起動します
3. ブラウザで `http://127.0.0.1:8712` を開く — 管理画面が表示されます

---

初回は使い方のチュートリアルが自動で始まります。
チャンネル名を設定画面で入力すれば、すぐに記録が始まります。

毎回起動するのが面倒な場合は、設定画面の
**「PC起動時に自動起動」をON**にしてください(起動し忘れ防止にもなります)。

### 起動中の確認と終了

起動すると、画面右下の通知領域(時計の近く)にアイコンが常駐します。

- アイコンがある = 動いている / ない = 止まっている
- マウスを乗せると「🟢 監視中: #チャンネル名」のように状態が出ます
- クリックで管理画面が開き、右クリックのメニューから終了できます

## できること

### 📦 特典待ち
節目の月数(6・12・24ヶ月など)に到達した視聴者が自動でカードに追加されます。
1人1枚のカードにまとまり、節目ごとに「特典済み」「対応不要」を記録できます。
カード下部のメモ欄に住所やサイズなどを書いて保存すると、履歴に残ります。

### 📚 特典履歴
渡した特典の台帳。CSVエクスポートに対応しています。
押し間違えた項目は「特典待ちに戻す」で復旧できます。

### 👥 サブスク一覧
視聴者ごとの通算・連続月数の一覧。チャットで取得できない人は手入力でき、
あとで本人がチャットで再サブスクすると自動的に正式な値へ上書きされます。
表示名の変更(✏)や記録の削除(🗑)も可能です。

### 🔮 到達予定
各視聴者が次に到達する節目を近い順に表示。特典の事前準備に使えます。

### 🏆 ランキング
コメント数・キーワード・ビッツ・ギフトの4種類を、累計/今月/直近7日で切り替え表示。
キーワードは表記ゆれ(かわいい・カワイイ・kawaii)をまとめて登録できます。

ギフト・ビッツは、ツール導入前の実績を**手入力で足す**こともできます。
入力した数は自動記録に加算されるため、配信中に増えた分が消えることはありません。

### 🖥 OBS連携
設定画面でURLをコピーしてOBSのブラウザソースに貼るだけで、配信画面に表示できます
(背景透過・自動更新)。

- **ランキング表示**: 種類(コメント数/キーワード/ビッツ/ギフト)と期間を選ぶとURLが生成されます
- **節目到達の祝福バナー**: 誰かが節目に到達した瞬間だけ、紙吹雪と効果音つきで表示されます

設定画面の「🎬 テスト発火」で、実際の到達を待たずに見え方を確認できます。
※OBSで音を出すには、ブラウザソースの「ページの音声をミュート」のチェックを外してください。

**効果音は好きな音源に変更できます。** 設定画面の「🔊 祝福バナーの効果音」から
mp3・wav・ogg・m4aなど(10MBまで)を登録でき、音量も調整できます。
未登録のときは内蔵のファンファーレが鳴ります。

### 🔗 Twitch連携(任意)
**連携しなくても上記の機能はすべて動きます。** 連携すると、チャットだけでは
分からない情報を追加で見られるようになります。

| 見られるもの | 内容 |
|---|---|
| サブスク名簿 | いまサブスクしている人の一覧(チャットで共有しない人も含む) |
| ギフトの贈り主 | 誰から贈られたサブスクかが分かります |
| ビッツ公式ランキング | ツール導入前を含む、Twitch集計の正確な総額 |
| フォロワー一覧 | フォローされた日時つき |
| 配信の目標 | フォロワー目標などの進捗 |

連携は「🔗 Twitch連携」画面のボタンを押し、**表示されたコードをTwitchのページに
入力するだけ**です。開発者登録もAPIキーの入力も不要です。

> **⚠ サブスクの継続月数は連携しても取得できません。**
> Twitchが月数を公開していないためで、月数は今までどおりチャットの記録と
> 手入力で管理します。また、サブスク名簿はアフィリエイト/パートナーの
> チャンネルでのみ取得できます。

## 主な設定

- **月数の数え方**: 「通算そのまま」と「今日から数える」を選べます。
  「今日から特典を始めます!」という場合は後者を選ぶと、長期サブスクの人に
  過去の節目分がまとめて積まれるのを防げます。
- **繰り返し間隔**: 6と入れると6・12・18…と上限なく節目が続きます。
- **対象ティア**: Tier 1/2/3/Prime ごとに特典対象を選べます。
  ※Prime(Amazonプライム特典のサブスク)は長期継続者に多いため、
  外すと対象から大きく漏れる場合があります。
- **コラボ配信中**: コラボ配信(Stream Together)では相方のチャンネルのチャットも
  一緒に流れてきます。既定ではそれらを記録しないため、自分のチャンネルのデータに
  他所の視聴者が混ざりません。OFFにすると相方の分も記録します。
- **PC起動時に自動起動**: サインイン時に自動で立ち上がり、起動し忘れによる記録漏れを防ぎます。
- **デスクトップ通知**: 既定はOFFです。ゲームを全画面で遊びながら配信していると、
  通知が出た瞬間に画面が切り替わってカーソルが引っ張られるためです。
  到達に気づきたい場合は、OBSオーバーレイの祝福バナーが配信を邪魔しません。
- **通知を消えないように**: 節目到達の通知を、自分で閉じるまで画面に残します(見逃し防止)。
  ただしWindowsからは目覚ましと同じ扱いになり、**全画面のゲーム中でも割り込みます**。
  ゲーム配信ではONにしないでください。

## テストモード(実配信を待たずに動作確認する)

```bash
python tools/replay.py tests/sample_lines.txt
```

`tests/sample_lines.txt` に生のIRCログを追記すれば、任意のパターンを試せます。

## 開発者向けツール(配布物には含まれません)

| ファイル | 用途 |
|---|---|
| `commit.bat` | 変更をコミットしてGitHubへプッシュするだけ |
| `release.bat` | **これ1つでリリース完了**: バージョン更新→インストーラー自動ビルド→コミット・プッシュ→GitHubリリース作成→ZIP+インストーラー添付 |
| `build_installer.bat` | インストーラーだけ作りたいとき(直渡し用など) |

インストーラーのビルドには [Inno Setup 6](https://jrsoftware.org/isdl.php)(無料)が必要です。

リリースすると、旧バージョンの利用者の画面左下に更新のお知らせが表示されます。

## 更新がWindowsにブロックされたとき

署名のない個人開発アプリのため、環境によってはワンクリック更新が
SmartScreenやセキュリティソフトにブロックされることがあります。その場合:

1. [Releases](https://github.com/injeharu/stream-tool/releases/latest) から
   最新の `TokutenDaicho-Setup-vX.Y.Z.exe` をダウンロード
2. 実行する(「WindowsによってPCが保護されました」が出たら「詳細情報」→「実行」)

**それだけで更新完了です。アンインストールは不要で、記録したデータも消えません**
(データは別の場所に保存されているため、何度上書きインストールしても残ります)。

## 既知の制約

- **視聴者が再サブスク時に「共有しない」を選ぶと、チャットにイベントが流れず自動取得できません。**
  この場合は「サブスク一覧」画面から手動で月数を入力してください。
  なお[Twitch連携](#-twitch連携任意)をすると、**その人がサブスクしていること自体は
  名簿で確認できます**(月数は取得できないため手入力のままです)。
- **連続月数(streak)は、視聴者が「連続表示」を有効にしている場合のみ取得できます。**
- **過去のデータは遡れません。** ツールを起動した後に発生した再サブスクから蓄積されます。
- **ツールが起動していない間のイベントは取得できません。** 配信開始前の起動を推奨します。
  設定の「PC起動時に自動起動」をONにしておくと起動し忘れを防げます。
- **ソース実行版でフォルダを移動・改名した場合、自動起動の登録が無効になります。**
  移動後に設定画面で自動起動を一度OFF→ONし直してください
  (インストーラー版は場所が固定されるため、この問題は起こりません)。

## データの保存場所とプライバシー

- すべてローカルの `data.db`(SQLite)に保存されます。**外部サーバーへの送信は一切ありません。**
  - インストーラー版: `%APPDATA%\TokutenDaicho\`
  - ソース実行版: ツールのフォルダ直下
- 起動のたびに `backups` フォルダへ日次バックアップ(直近3世代)が自動作成されます。
- 視聴者データ・バックアップは、**配布物にもGitHubにも一切含まれません。**
- チャンネルごとにデータは分かれて保存されるため、監視先を切り替えても混ざりません。
- 外部への通信は「Twitchチャットの受信」「新バージョンの有無の確認」、
  および**Twitch連携を使う場合のみ**「Twitch公式APIからの情報取得」です。
- Twitch連携で発行される鍵(アクセストークン)も同じ `data.db` に保存され、
  **外部へ送信されることも、配布物に含まれることもありません。**
  パスワードの入力は一切求めません(ログインはTwitchの公式ページで行われます)。
  連携は画面の「連携を解除する」でいつでも解除できます。
