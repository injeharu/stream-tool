# 配信サポートツール(グッズ発送台帳)

Twitchのチャットを匿名で監視し、サブスク月数が設定した節目(閾値)に到達した視聴者を
自動でグッズ発送待ちリストに載せる、配信者向けの常駐ツールです。

## セットアップ

```bash
pip install -r requirements.txt
python app.py
```

初回起動時にチャンネル名の入力を求められます。以降は自動で設定を読み込みます。
起動後、ブラウザで `http://127.0.0.1:8712` を開くと管理画面が表示されます。

OAuthやAPIキーの登録は不要です。匿名の読み取り専用IRC接続のみを使用します。

## テストモード(実配信を待たずに動作確認する)

```bash
python tools/replay.py tests/sample_lines.txt
```

`tests/sample_lines.txt` に生のIRCログを追記すれば、任意のパターンを試せます。

## 既知の制約

- **視聴者が再サブスク時に「共有しない」を選ぶと、チャットにイベントが流れず自動取得できません。**
  この場合は「サブスク一覧」画面から手動で月数を入力してください。手入力した値は、
  次に本人がチャットで共有ありの再サブスクをすると自動的に正式な値へ上書きされます。
- **連続月数(streak)は、視聴者が「連続表示」を有効にしている場合のみ取得できます。**
- **過去のデータは遡れません。** ツールを起動した後に発生した再サブスクから蓄積されます。
- **ツールが起動していない間のイベントは取得できません。** 配信開始前に起動しておく運用を想定しています。

## データの保存場所

すべてローカルの `data.db`(SQLite)に保存されます。外部サーバーへの送信は一切行いません。
